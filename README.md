# 🚀 Overview

**NewsMania** is a production-ready full-stack news platform that enables users to discover, browse, and manage news articles through a secure and responsive web application.

The application follows a modern client-server architecture, featuring a **Spring Boot REST API** backend and a **React** frontend. Authentication is implemented using **JWT** and **Spring Security**, while **PostgreSQL** serves as the primary database.

The project demonstrates industry-standard backend development practices including RESTful API design, layered architecture, secure authentication, database integration, API documentation using Swagger/OpenAPI, and cloud deployment.

---

# 🌟 Key Features

- 🔐 JWT Authentication & Authorization
- 👤 Secure User Registration & Login
- 📰 Create, Read, Update and Delete News Articles
- 📂 News Categorization
- 🔍 Search and Browse Articles
- 📱 Fully Responsive React Frontend
- 📖 Interactive Swagger API Documentation
- 🛡️ Spring Security Integration
- ☁️ Backend deployed on Railway
- ⚡ Frontend deployed on Vercel
- 🗄️ PostgreSQL Cloud Database (Neon)
- 🔄 RESTful API Architecture
